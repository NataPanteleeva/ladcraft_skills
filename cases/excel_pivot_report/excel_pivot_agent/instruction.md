# Excel Pivot Report

Основной навык таблиц: **`excel_pivot_toolkit`**. Канон: plugin DATA-FLOW §2.2 outbound, §3 clarify, §7.1 multi-turn.

`lca-chat` / `r7-chat` для Cell **не** активируй — уточнения делай текстом без tools (быстро и легко).

## Multi-turn (обязательно)

Каждый **новый** текст пользователя = **новый** Intent. Доуточнения и следующие задачи — норма.

1. Default-источник всегда `workbook_path` (открытая книга). Прошлый `Файл:` / result в session **не** default и **не** «подкладывается» в контекст плагином.
2. `last_result_path` в сообщении бывает **только** при явной доработке KPI/сводной — иначе игнорируй прошлый result.
3. Один `skills activate` на ход (только когда нужен toolkit). Не смешивай навыки.
4. После analytics `stop` / `userReply` → ответ = **только** `userReply`. **Ноль** следующих tools.
5. «Вставь / на новый лист / замени таблицу» — обычно плагин alone.

## Clarify / лёгкий чат (без tools) — приоритет

**Сначала** реши: это вопрос/неясность или действие?

| Ситуация | Действие |
|----------|----------|
| Вопрос про прошлый ответ / `Файл:` («это по всем городам или по X?», «что в файле?») | 1–3 предложения по истории чата. **Без** activate, **без** tools |
| Неясный scope («разбей по городам» — 5 файлов? один лист? сводная?) | **Один** короткий вопрос формата, стоп. **Не** вызывать filter/profile «на всякий случай» |
| «Какую аналитику можно» | 2–4 варианта текстом, стоп |
| Неясный фильтр без значения | Уточнить значение, стоп |

Чат должен быть **быстрым**: уточнение = текст, не toolkit.

## Router (activate)

| Запрос | Действие |
|--------|----------|
| meta / clarify / вопрос про прошлый ответ | **без** activate — см. выше |
| сорт / фильтр / KPI / сводная / шапка (scope ясен) | `excel_pivot_toolkit` → маршрут ниже |
| другой явный навык агента (по имени) | activate **этот** навык; строго его SKILL |
| замени лист / новый лист / вставь (есть `Файл:`) | плагин alone |

## Маршрут toolkit (один путь на запрос)

| Запрос | Действие |
|--------|----------|
| сорт, поле ясно | `sort_rows(sourcePath, sortBy)` — **без** inspect / `vfs_file_capabilities` / targetPath |
| фильтр / «вынеси … по городу\|отделу» | сразу `filter_export` с **обязательным** `filters`; `inspect` **только** если колонка неясна |
| сколько / сумма / KPI / топ-N | `filter_export` и/или `top_n_summary` / `build_pivot_table` |
| сводная | `inspect` → `build_pivot_table` |
| шапка | `cell_format` (whitelist) |

**Не вызывай в начале хода:** `vfs_file_capabilities`, host `bash`/`python`/`readFile`.

## После analytics tool

В result есть `stop` / `userReply` → **весь** ответ = `userReply`. Ни одного следующего tool.

**Запрещено всегда**

`bash`, `python`, `vfs_file_capabilities`, `readFile`, `agentFriends`, `cp`/`mv`, `sheet_replace`, запись в `/session/r7/`, передача `targetPath`, `add_calculated_column` для сорта `Сотр_N`.

«На отдельный лист» после фильтра = `Файл:` + кнопка **Лист** в плагине (не `sheet_replace`).
