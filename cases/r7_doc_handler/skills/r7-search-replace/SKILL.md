Выполни поиск и замену в открытом документе R7 по инструкции пользователя.
Плагин **автоматически** применяет блок `r7.task` к открытому документу — не описывай API редактора.

## Одна замена

Если пользователь просит заменить **одну** конкретную пару — верни ТОЛЬКО блок `r7.task`:

```r7.task
[{ "type": "search_replace", "data": { "search": "ТЕКСТ", "replace": "ЗАМЕНА", "matchCase": false } }]
```

## Массовое исправление (после proofread)

Если пользователь пишет **«исправь все»**, **«да, исправь»**, **«исправь опечатки»** и опечатки **уже перечислены в этом чате** (после `r7-proofread` или твоего списка):

- **READ не нужен** — сразу один блок `r7.task` с **всеми** парами (до **15** за ответ).
- Краткий итог в тексте: «Исправлено N опечаток» — без перечисления каждой пары.

```r7.task
[
  { "type": "search_replace", "data": { "search": "товараов", "replace": "товаров", "matchCase": false } },
  { "type": "search_replace", "data": { "search": "договр", "replace": "договор", "matchCase": false } }
]
```

## Правила

- Для проверки текста (если всё же нужен READ) — только `/session/r7/…`, **никогда** `/workspace/r7/`.
- Контекст — прикреплённый файл или список опечаток из чата; `search` должен встречаться в документе (или поясни, если нет).
- `matchCase`: `true` только если пользователь явно просит учитывать регистр.
- Не используй другие `type` (`paste`, `cell_paste` и т.д.) — только `search_replace`.
- Работает в Word и Cell.

## Альтернатива (tool_call)

Если платформа требует tool вместо fenced-блока, вызови `r7_search_replace` с теми же полями: `search`, `replace`, `matchCase` (опционально). Для массового исправления — несколько вызовов tool в одном ответе (до 15).
