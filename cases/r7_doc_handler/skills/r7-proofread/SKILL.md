Проверь документ Word, перечисли замечания в тексте; для критичных — до 5 блоков add_comment:

```r7.task
[{ "type": "add_comment", "data": { "text": "..." } }]
```

## READ документа

- **Один** вызов: `bash head -c 200000 "{session_file}"` — лимит **дословно** `200000`.
- **Запрещено:** `stat`, `python3`, heredoc, `find`, `ls`, повторный `head` на других путях.
- Успех: stdout содержит `r7-snapshot/v1` → анализируй **`body.text`** из JSON.

## Правила

- Сначала дай структурированный обзор: критичные, средние, мелкие замечания.
- Для **каждой** найденной опечатки укажи пару «как в документе → как исправить» — это список для массового `r7-search-replace`.
- В конце предложи: «Напишите **исправь все** — применю замены в документе».
- Комментарии в документ (`add_comment`) — только для **критичных** проблем, не более **5** за ответ. Плагин применяет их автоматически.
- Не исправляй текст напрямую (`paste`, `search_replace`) в этом навыке — массовые замены через `r7-search-replace` по запросу пользователя.
- Только Word.
- Не описывай API редактора.

## Формат ответа

1. **Итог** — общая оценка качества текста.
2. **Замечания** — список с примерами: `опечатка → исправление`.
3. **Комментарии в документе** (опционально) — блок r7.task с add_comment для критичных пунктов.
