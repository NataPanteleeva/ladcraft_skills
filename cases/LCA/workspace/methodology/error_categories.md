# Категории ошибок (школьная иерархия)

Используется навыком `lca-proofread`. Плагин читает только fence `r7.proposal`; поле `category` у item — опционально.

| # | category | Заголовок секции | Что это |
|---|----------|------------------|---------|
| 1 | `orthography` | Орфографические | Неправильная буква / написание слова (`карова`, `трансформацыя`) |
| 2 | `punctuation` | Пунктуационные | Знаки препинания (запятая, `!!!`, точка, тире) |
| 3 | `grammar` | Грамматические | Словообразование (`ихний`), морфология (`ехай`), синтаксис (`оплатите за`, `по приезду`, `согласно плана`) |
| 4 | `speech` | Речевые / стилистические | Лексика (`одеть/надеть`, `дешёвые цены`), тавтология, канцелярит, жаргон, смешение «ты/Вы» |
| 5 | `logic` | Логика | Противоречия дат, цифр, статусов — **только** если просили логику или полную проверку |

## Порядок при полной проверке

Выводить секции 1→4 (пустые не показывать). Секцию «Логика» — только по запросу логики / «полная проверка» с логикой.

## Scoped-запрос

«Только орфографию» / «пунктуационные» / «грамматические» / «стилистические» / «речевые» → в ответе **одна** секция и в fence только items с этой `category`.

## Применение

- «исправь все» / «исправь правописание» / кнопка **Все: N–M** — только `orthography` + `punctuation` + `grammar` (без речи и логики).
- Чипы **Орфо** / **Пункт** / **Грамм** — только соответствующая категория.
- «исправь орфографию» / «исправь пунктуацию» / «исправь грамматику» — категория в чате.
- «исправь стилистику» / «исправь логику» — речь и логика **только через диалог** (кнопок нет).
- «исправь 1, 3» — по номерам (любые категории).
