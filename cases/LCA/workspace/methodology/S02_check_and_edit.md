# С-02 — Проверка и правка (методика)

## Порядок

1. Уточнить вид документа / контекст.
2. `/workspace/methodology/contexts.md` → slug.
3. **`proofread_core_rules.md`** + `error_categories.md` + `checklists/proofread.md` (+ slug RULES для speech).
4. Текст из **session snapshot**.
5. Таблица(ы) по категориям (орфо / пункт / грамм / речь; логика — по запросу) + fence с `category` — документ не менять.
6. Согласие: «исправь все» / «Правописание» = орфо+пункт+грамм; стиль/логика — «исправь стилистику» / «исправь логику» / номера.
7. Плагин применяет findings; перепись целиком — `lca-compose`.

High-confidence только; soft-cap ≤15 mechanical; вне Core не углубляться.

## Режимы

| Режим | Когда | Результат |
|-------|--------|-----------|
| Полная проверка | «проверь» | До 4 секций (+ логика по запросу) |
| Scoped | «только орфографию» / «стилистические» | Одна категория |
| Правка | «исправь все» (правописание) / категорию / N | Плагин search_replace |
| Перепись | «перепиши», Йода, для руководства | `lca-compose` |

## Не делать

- Менять документ до согласия.
- Смешивать категории в scoped-ответе.
- Отвечать одной плоской таблицей на полную проверку.
