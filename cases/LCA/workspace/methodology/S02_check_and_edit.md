# С-02 — Проверка и правка (методика)

## Порядок

1. Уточнить **вид документа / контекст** (из запроса или спросить одним вопросом).
2. Прочитать `/workspace/methodology/contexts.md` → slug.
3. Прочитать `/workspace/rules/{slug}/RULES.md` (+ при необходимости `/workspace/checklists/proofread.md`).
4. Прочитать текст из **session snapshot** (не из workspace).
5. Сформировать **одну** таблицу замечаний (№ | Было | Стало) — документ **не** менять.
6. Запросить согласие: «исправь все» / «исправь 1, 3».
7. Только после согласия — навык замены (`lca-search-replace`).
8. Перепись / смена стиля: сначала полный черновик в чате (`lca-rewrite`), в документ — только после «вставь» / «одобряю».

## Режимы

| Режим | Когда | Результат |
|-------|--------|-----------|
| Рекомендации в чате | «проверь», без «исправь» | Только таблица + согласие |
| Правка опечаток | «исправь все» / N | Tools search_replace, без второй таблицы |
| Перепись / стиль | «перепиши», «как Йода» | Черновик → после одобрения replace_selection |

## Не делать

- Менять документ на шаге проверки или до одобрения черновика.
- Искать правила через обход всего диска.
- Смешивать наборы правил разных slug без указания пользователя.
