# Каталог: форматы документов и стили оформления

Агент: сопоставь формулировку пользователя со **slug** (служебные таблицы внизу).  
Правила: `/workspace/rules/{slug}/RULES.md`  
Образец: `/workspace/style/{slug}/sample.md` (если есть).

## Как отвечать на «какие есть стили / форматы / варианты оформления»

1. **Без** `skills activate`.
2. Прочитай **этот файл** (`bash head -c 50000 /workspace/methodology/contexts.md`).
3. Покажи пользователю **только готовые таблицы ниже** (русские названия + как попросить + суть).  
   **Не показывай** колонку slug, технические идентификаторы и служебные таблицы сопоставления.
4. Не выдумывай пункты вне таблиц.
5. **Не** читай и **не** вставляй в ответ содержимое `style/*/sample.md` — только таблицы из этого файла.

## Как отвечать на «покажи шаблоны» / «какие есть шаблоны»

1. **Без** `skills activate` и **без** чтения `sample.md`.
2. Ответ — **короткий список** (≤20 строк) из таблиц «Форматы» и «Стили» ниже.
3. В конце одна фраза: «Напишите вид или стиль — подготовлю текст / проверю по правилам.»
4. **Запрещено:** дамп примеров из sample, длинные цитаты, несколько sample подряд, блоки `>` с образцами.

## Форматы документов (вид текста)

| Формат | Как попросить | Суть |
|--------|---------------|------|
| **Нейтральный текст** | «нейтрально», «просто текст» | Ясный деловой тон |
| **Деловое письмо / служебная записка** | «письмо», «служебная записка» | Обращение → цель → просьба → подпись |
| **Договор / соглашение** | «договор», «соглашение», «оферта» | Юридически аккуратные формулировки |
| **Объявление / анонс** | «объявление», «анонс», «пост» | Что / когда / где / для кого / CTA |
| **Служебный отчёт** | «отчёт», «итоги периода» | Период → итог → результаты → риски → планы |

## Стили переписки (перепись / тон)

| Стиль переписки | Как попросить | Суть |
|-----------------|---------------|------|
| **Стиль Йоды** | «как Йода», «в стиле Йоды» | Инверсия порядка слов (демо) |
| **Краткая выжимка** | «краткая выжимка», «для руководства», «в тезисах» | Суть → факты → решение |
| **Официально-деловой** | «официально», «канцелярский», «перепиши официально» | Клише, пассив, без эмоций |
| **Научный** | «научно», «академический», «перепиши научно» | Термины, логика, без «я» |
| **Публицистический** | «публицистически», «как в СМИ», «для блога» | Риторика, образы, вовлечение |
| **Художественный** | «художественно», «литературно», «образно» | Тропы, ритм, образы |
| **Разговорный** | «разговорно», «неформально», «по-простому», «для чата» | Живая устная речь |

## Служебные таблицы сопоставления (только для агента, не для ответа пользователю)

### Виды документов

| slug | Ключевые слова |
|------|----------------|
| `general` | не указан вид; «нейтрально»; «просто текст» |
| `letter` | письмо, служебная записка, обращение, исходящее |
| `contract` | договор, соглашение, приложение к договору, оферта |
| `announcement` | объявление, новость, анонс, пост, уведомление |
| `report` | отчёт, служебный отчёт, итоги периода |

### Стили речи (перепись)

| slug | Ключевые слова |
|------|----------------|
| `yoda` | «как Йода», «в стиле Йоды», инверсия Йоды |
| `executive` | «краткая выжимка», «для руководства», «executive», «в тезисах», «сжать для совещания» |
| `official` | «официально», «деловой стиль», «канцелярский», «бюрократический», «перепиши официально» |
| `scientific` | «научно», «научный стиль», «академический», «для диссертации», «перепиши научно» |
| `publicistic` | «публицистический», «как в СМИ», «для блога», «газетный», «перепиши публицистически» |
| `literary` | «художественный», «литературный», «образно», «как в книге», «перепиши художественно» |
| `colloquial` | «разговорный», «неформально», «по-простому», «для чата», «перепиши разговорно» |

**Стилистика vs формат:** стили речи — для **переписи** тона; форматы — жанр документа.  
Если пользователь явно просит стиль — бери его slug (`rules/{slug}/RULES.md`, sample если есть), даже если исходник — письмо или отчёт.  
`official` ≠ формат «письмо/договор»: это усиленный канцелярский тон переписи.

**Приоритет:** явный стиль переписки > формат документа > `general`.

**Если не уверены** — `general` и одной фразой предложите уточнить формат или стиль.
