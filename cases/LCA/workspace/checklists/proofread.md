# Чек-лист: лингвистическая проверка (proofread)

Перед выдачей таблицы замечаний:

- [ ] Определён slug контекста (`contexts.md`) или взят `general`
- [ ] Прочитан `/workspace/rules/{slug}/RULES.md`
- [ ] Прочитан текст из session snapshot / выделения
- [ ] Замечания сформулированы как пары «Было → Стало»
- [ ] В ответе **одна** таблица
- [ ] Есть блок согласия («исправь все» / «исправь N»)
- [ ] Документ **не** изменён в этом ходе
