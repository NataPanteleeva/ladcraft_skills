# Шаблоны заданий пользователя — проверка (С-02)

Эталон формулировок для приёмочных тестов и обучения методологов.  
В скобках — ожидаемый навык / поведение агента.

## Каталог БЗ (без навыка)

```
Какие есть правила и стили?
```
→ без activate: `head` `/workspace/methodology/contexts.md` → показать **готовые таблицы** с русскими названиями (форматы + стили); при необходимости `ls` `/workspace/rules` и `/workspace/style` только для сверки.

```
Покажи шаблоны
```
→ **без** activate и **без** чтения `sample.md`: краткая таблица имён форматов/стилей из `contexts.md` (как попросить) + одна фраза «укажите вид». Запрещён дамп примеров.

## Проверка без правки документа

```
Проверь текст: орфография, грамматика, пунктуация, стиль и логика. Только рекомендации.
```
→ `lca-proofread`, секции по категориям + fence с `category`.

```
Проверь только орфографию. Только рекомендации.
```
→ `lca-proofread`, секция «Орфографические» только.

```
Предложи стилистические исправления. Только рекомендации.
```
→ `lca-proofread`, только `speech` (не смешивать с орфо).

```
Проверь текст на опечатки. Вид документа: договор.
```
→ `lca-proofread`, slug `contract`.

```
Проверь стиль служебной записки. Только рекомендации в чате.
```
→ `lca-proofread`, slug `letter` (акцент speech + нормы письма).

```
Найди грамматические ошибки. Контекст: объявление.
```
→ `lca-proofread`, slug `announcement`, только `grammar`.

## После списка — согласие на правку

```
исправь все
```
→ плагин — все items текущего proposal.

```
исправь стилистику
```
→ плагин — только items с `category: speech` (если category нет — не трогать чужие пункты).

```
исправь орфографию
```
→ плагин — только `orthography`.

```
исправь 1, 3
```
→ плагин — только пункты 1 и 3.

```
Замени только «в течении» на «в течение», остальное не трогай.
```
→ одна (или целевые) замены.

## Стиль Йоды (не опечатки)

```
Перепиши выделенный фрагмент как Йода. Вставь правку в документ.
```
→ `lca-compose` (rewrite), slug `yoda` (`rules/yoda`, `style/yoda`).

```
Проверь: достаточно ли текст звучит как Йода? Только замечания в чате.
```
→ `lca-proofread`, slug `yoda` (критерии из RULES §5).
