# Шаблоны заданий пользователя — генерация (С-01)

## Только в чат

```
Напиши деловое письмо поставщику: задержка поставки на 5 дней, просьба новый график. Только в чат, в документ не вставляй.
```
→ `lca-generate`, slug `letter`, без paste.

## В чат и в документ

```
Составь короткое объявление о собрании 20 июля в 15:00, аудитория 301. Вставь в документ в позицию курсора.
```
→ `lca-generate` + `r7_paste` / `r7_paste_text`.

## Фрагмент договора

```
Напиши пункт договора об ответственности сторон за просрочку оплаты (нейтральный шаблон, без сумм). Вид: договор.
```
→ `lca-generate`, slug `contract`, опора на `style/contract/sample.md`.

## Отчёт

```
Сгенерируй краткий отчёт за июнь: выполнено 3 задачи, 1 риск по срокам. Структура как служебный отчёт.
```
→ `lca-generate`, slug `report`.

## Стиль Йоды

```
Перепиши фразу в стиле Йоды: «Будущее этого мальчика является туманным». Только в чат.
```
→ `lca-compose` (rewrite), slug `yoda`, опора на `rules/yoda/RULES.md` и `style/yoda/sample.md`.

```
Напиши два предложения как Йода: про силу привычки учиться. Вставь в документ.
```
→ `lca-compose` + paste после согласия, slug `yoda`.

## Для руководства (executive)

```
Перепиши выделенный фрагмент для руководства: кратко, в тезисах для совещания. Только в чат.
```
→ `lca-compose` (rewrite), slug `executive`, опора на `rules/executive/RULES.md` и `style/executive/sample.md`.

```
Сжать текст в управленческий brief для начальства. Вставь у курсора после согласования.
```
→ `lca-compose`, slug `executive`.
