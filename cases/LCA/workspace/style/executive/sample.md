# Образец стиля: executive (краткая выжимка)

Краткая выжимка. Ниже — пары «как было → краткая выжимка» и эталонный brief.

## Базовые превращения

| Как было | Краткая выжимка |
|----------|-----------------|
| В рамках осуществления мероприятий по оптимизации логистики хотелось бы обратить Ваше внимание на то, что поставка оборудования по договору № 12/2026, к сожалению, может быть смещена примерно на две недели относительно ранее согласованного графика | **Суть:** поставка по договору № 12/2026 сдвигается ~на 2 недели. **Просьба:** подтвердить новый график или направить замечания. |
| С учётом вышеизложенного просим Вас рассмотреть возможность предоставления дополнительной информации в удобные для Вас сроки | Нужна доп. информация. Укажите срок ответа (дата). |
| Команда в целом хорошо поработала над проектом, было сделано много полезного | Результаты: … (конкретика из исходника). Осталось: … |

## Эталонный brief (учебный)

**Суть.** Поставка оборудования по договору № 12/2026 переносится на ~2 недели.

**Факты**
- Договор: № 12/2026
- Причина в исходном тексте: сдвиг на стороне поставщика (если указана — сохранить; иначе не выдумывать)
- Новый ориентир: согласовать график до 25.07.2026

**Решение / просьба.** Подтвердить согласие с графиком либо направить замечания до 25.07.2026.

## Заметки для генерации / переписывания

1. Сначала выдели факты и просьбу из исходника.
2. Сожми в схему: Суть → Факты → Решение/просьба.
3. Не копируй учебные реквизиты из образца, если пользователь дал свой текст.
