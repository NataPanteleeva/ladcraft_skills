# Правила: report (отчёт)

## 1. Назначение и тон

- Фактический, структурированный стиль.
- Выводы отделены от описания работ.

## 2. Структура

1. Период / объект отчёта
2. Краткий итог (executive summary)
3. Основные результаты (списки или подпункты)
4. Проблемы / риски (если есть)
5. Планы / предложения

## 3. Лексика

| Предпочтительно | Избегать |
|-----------------|----------|
| измеримые формулировки | «много», «хорошо поработали» без фактов |
| прошедшее время для фактов | смешение будущего и факта без маркеров |

## 4. Запреты

- Скрывать существенные риски, если они есть во входных данных пользователя.
- Рекламный тон вместо отчётного.

## 5. Типовые ошибки

- Несогласованные списки («1.» затем «•»).
- Путаница «в течение / в течении».

## 6. Критерии «принято»

- Есть итог и факты.
- Структура отчёта читаема.

## 7. При переписи

Сохраняй факты, цифры и риски из исходника. Выстраивай схему: период → итог → результаты → риски → планы (см. `style/report/sample.md`). Не подменяй отчёт рекламным тоном и не выдумывай KPI.
