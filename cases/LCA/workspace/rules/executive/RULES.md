# Правила: executive (краткая выжимка)

> Стилистический вариант (не вид делового документа).  
> Ключевые слова: «краткая выжимка», «для руководства», «executive», «кратко для начальства», «в тезисах», «сжать для совещания», «управленческий стиль».

## 1. Назначение и тон

- Переписать **любой** фрагмент (письмо, абзац, черновик, выжимку) в вид, удобный для руководителя на совещании.
- Тон: спокойный, уверенный, деловой; без юмора, эмодзи и пафоса.
- Цель читателя — за 20–30 секунд понять **суть, факты и нужное решение/действие**.

## 2. Структура

Типовая схема brief:

1. **Суть** — одно–два предложения (что произошло / о чём речь).
2. **Факты** — 3–7 тезисов или короткий нумерованный список (цифры, сроки, имена из исходника).
3. **Решение / просьба** — что нужно от адресата или какой следующий шаг (если это следует из текста).

Допустимо без заголовков, если фрагмент короткий: абзац «суть» + список фактов.

При переписи:
- сохраняй смысл, цифры, даты, имена и обязательства из исходного текста;
- сжимай воду и вводные; не раздувай объём;
- не превращай в полный отчёт жанра `report`, если пользователь просил только «для руководства».

## 3. Лексика и формулировки

| Предпочтительно | Избегать |
|-----------------|----------|
| «срок — 25.07.2026» | «в ближайшее время», «как можно скорее» без даты |
| «нужно согласовать» | «осуществить согласование в рамках…» |
| «риск: …» | «имеются определенные сложности» без конкретики |
| активный залог, короткие фразы | канцелярит ради канцелярита |

## 4. Запреты

- Выдумывать KPI, суммы, сроки и выводы, которых нет во входном тексте.
- Шутки, метафоры «Звёздных войн», разговорный сленг.
- Длинные абзацы без структуры (простыня вместо тезисов).
- Менять смысл обязательства или скрывать существенный риск, если он есть в исходнике.

## 5. Типовые ошибки для проверки (если просят «проверь / перепиши для руководства»)

- Текст длиннее исходника без добавления фактов — сожми.
- Нет явной «сути» в начале.
- Размытые формулировки вместо конкретных дат/цифр из исходника.
- Смешение рекомендаций и фактов без маркеров.

## 6. Критерии «принято»

- Руководитель видит суть без чтения всего исходника.
- Факты и цифры из исходного текста сохранены.
- Есть понятный следующий шаг или явно сказано, что решение не требуется.
- Тон управленческий, без канцелярской воды.
