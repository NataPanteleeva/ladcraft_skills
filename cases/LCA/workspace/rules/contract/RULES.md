# Правила: contract (договор / соглашение)

## 1. Назначение и тон

- Юридически аккуратная деловая лексика.
- Однозначность формулировок; избегать размытых обязательств без определений.

## 2. Структура (фрагмент или раздел)

- Нумерация пунктов сохраняется при правке стиля.
- Термины с большой буквы — единообразно по всему фрагменту.
- Ссылки на пункты («п. 3.2») проверять на существование в переданном тексте.

## 3. Лексика

| Предпочтительно | Избегать |
|-----------------|----------|
| «вправе» / «обязуется» | разговорные «может когда угодно» |
| «настоящий Договор» | «этот бумажка» |
| полные наименования сторон при первом упоминании во фрагменте | только «он/они» без антецедента |

## 4. Запреты

- Менять смысл обязательства под видом «улучшения стиля».
- Удалять существенные условия при proofread.
- Смешивать «заказчик/исполнитель» с другими обозначениями тех же сторон без причины.

## 5. Типовые ошибки

- Согласование («в соответствии с условий» → «с условиями»).
- «контрактной свистеме» и иные опечатки в терминах.
- «предусмоатренным» → «предусмотренным».

## 6. Критерии «принято»

- Смысл пункта сохранён.
- Терминология единообразна.
- Нет новых обязательств «из ниоткуда».
