# Правила: general (нейтральный стиль)

> Шаблон для копирования в `rules/{новый_slug}/RULES.md`.  
> Контекст по умолчанию, если вид документа не указан.

## 1. Назначение и тон

- Ясный деловой / нейтральный русский язык.
- Уважительно к адресату; без сленга и канцелярских нагромождений.

## 2. Структура

- Короткие абзацы (2–5 предложений).
- Сначала суть, потом детали.
- Списки — только если перечисление упрощает чтение.

## 3. Лексика

| Предпочтительно | Избегать |
|-----------------|----------|
| «в течение» | «в течении» (кроме «в течении реки») |
| «согласно договору» | «согласно договора» |
| конкретные даты и факты | размытые «в ближайшее время» без нужды |

## 4. Запреты

- Орфографические и пунктуационные ошибки.
- Двойные пробелы, «ё»/«е» по желанию Заказчика единообразно в одном тексте.
- Смешение «ты» и «Вы» без причины.

## 5. Типовые ошибки для проверки

- Опечатки в корнях и окончаниях.
- «не» слитно/раздельно с причастиями по контексту.
- Согласование подлежащего и сказуемого.

## 6. Критерии «принято»

- Текст понятен с первого чтения.
- Нет нарушений п. 3–5.
- Смысл исходного задания / исходного фрагмента сохранён.
