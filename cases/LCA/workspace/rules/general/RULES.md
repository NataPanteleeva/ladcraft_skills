# Правила: general (нейтральный стиль)

> Контекст по умолчанию. Категории — `/workspace/methodology/error_categories.md`.  
> **Mechanical proofread** (орфо / пункт / грамм) — канон  
> `/workspace/methodology/proofread_core_rules.md` (не дублировать здесь полностью).

## 1. Назначение и тон

- Ясный деловой / нейтральный русский язык.
- Уважительно к адресату; без сленга и канцелярских нагромождений.

## 2. Структура

- Короткие абзацы (2–5 предложений).
- Сначала суть, потом детали.

## 3–5. Орфография, пунктуация, грамматика

См. **Core** в `proofread_core_rules.md` (блоки A–C).  
Кратко для генерации текста (не proofread):

- Орфо: верные буквы; *чтобы / также / не* с глаголами — по Core.
- Пункт: вводные, однородные; без `,:` и лишней запятой перед соединительным «и».
- Грамм: *согласно плану*, *в течение*, согласование.

Не углубляться в школьные частности из раздела «Вне core».

## 6. Речевые / стилистические (`speech`)

- Лексика: `одеть` → `надеть`; `дешёвые цены` → `низкие цены`.
- Тавтология / плеоназм; канцелярит: `в целях осуществления` → `чтобы`.
- Жаргон; смешение «ты» и «Вы».
- Грубая сочетаемость: `сделали решение` → `приняли решение`.

Детали — Core блок D и `style/{slug}/sample.md` при generate.

## 7. Логика (`logic`, по запросу)

- Противоречия дат, цифр, статусов.
- Правка — конкретная пара фрагментов, не абстрактный совет.

## 8. Критерии «принято»

- Текст понятен с первого чтения.
- Нет явных нарушений Core A–C (и D/7, если проверяли).
- Смысл исходного фрагмента сохранён.
