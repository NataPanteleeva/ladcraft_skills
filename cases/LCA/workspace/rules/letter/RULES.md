# Правила: letter (деловое письмо / служебная записка)

## 1. Назначение и тон

- Официально-деловой тон; обращение на «Вы».
- Цель письма ясна в первом абзаце.

## 2. Структура

Типовая схема:

1. Обращение (например «Уважаемый Иван Иванович!»)
2. Повод / цель
3. Суть и обоснование
4. Просьба или предложение
5. Заключение + подпись (должность, ФИО)

Не смешивать несколько несвязанных тем в одном письме без явного запроса.

## 3. Лексика

| Предпочтительно | Избегать |
|-----------------|----------|
| «просим рассмотреть» | «прошу глянуть» |
| «направляем» | «скидываем» |
| «в соответствии с» | канцелярит ради канцелярита («во исполнение вышеизложенного» без нужды) |

## 4. Запреты

- Разговорный сленг, эмодзи (если Заказчик не оговорил иное).
- Угрозы и ультиматумы без правовой необходимости.
- Пустые вводные без содержания.

## 5. Типовые ошибки

- «в течении срока» → «в течение срока»
- Неверное склонение в обращении («Уважаемый Ивана…»)
- Пропуск запятой после обращения.

## 6. Критерии «принято»

- Есть цель и понятное действие для адресата.
- Структура письма соблюдена.
- Соответствует нейтрально-деловому тону.
