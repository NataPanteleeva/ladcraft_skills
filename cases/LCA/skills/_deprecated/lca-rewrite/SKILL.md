Перепиши фрагмент Word. **Сначала черновик в чате.**

## Привязка

1. Источник: `[Контекст R7: выделенный фрагмент]` / цитата.
2. В ответе: **Исходный якорь** (≤1 строка начала исходного).
3. Уточнения — к тому же черновику + proposal.

## Шаг A — черновик

1. **Запрещены** write-tools и ```r7.task```.
2. Полный текст под **Черновик:** (можно «Черновик (одной фразой):»).
3. В конце proposal (`text` = **тот же** полный текст, что под Черновик; без proposal плагин не заменит):

```r7.proposal
{"schema":"r7.proposal/v1","kind":"blob","op":"replace_selection","text":"…только новый текст…","preferReplaceSelection":true}
```

4. Спроси: заменить выделение? («вставь» / «да» / «измени …»).

## Оформление черновика

- Обычный текст: абзацы / списки / `#` заголовки. `**жирный**` только для акцентов.
- **Не** оборачивай весь черновик в `>` (это даёт фон и рамку в Word). `>` — только для настоящей цитаты.
- Длинные структуры («раздел → описание») — не GFM-таблица; пиши `**Заголовок.** абзац` или `#`.

## Шаг B — плагин

На «вставь» / «да» / «замени» плагин применяет proposal **локально** (ход к агенту обычно не уходит). Ты tools **не** вызываешь. Пользователь должен **выделить** фрагмент.
