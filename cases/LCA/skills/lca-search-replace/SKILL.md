Выполни замены в открытом документе **только после явного согласия**. Плагин применяет tool_calls автоматически.

## Когда вызывать этот навык

Только если пользователь уже видел список и написал одно из:

- **исправь все** / **да, исправь** / **исправь опечатки**
- **исправь 1, 3** / **только 2** — номера из таблицы предыдущего сообщения
- конкретную пару «замени X на Y»

Если согласия нет (только «проверь») — **не** этот навык; нужна проверка через `lca-proofread`.

## Primary

Вызови tool **`r7_search_replace`** (`search`, `replace`, `matchCase` опц.).

- «исправь все» → пары из **последней** таблицы замечаний в чате (до **15** вызовов).
- «исправь 1, 3» → только строки с этими №.
- Одна пара по запросу → один вызов.

## Ответ пользователю (без дублей)

После tool_calls — **коротко**, **без второй таблицы** и без повторения полного списка:

- Одна фраза: «Внёс N замен в документ» (или «Внёс замены по пунктам 1, 3»).
- Не дублируй markdown-таблицу «Было / Стало».
- Не пиши отдельный блок «Все опечатки успешно исправлены» + ещё одна таблица.

Список замечаний уже был в предыдущем ходе — достаточно статуса apply.

## Оформление

`SearchAndReplace` — plain text. Для HTML-оформления → `lca-rewrite`.

## Fallback

Только если tool недоступен — fence ```r7.task``` с search_replace.

## r7.event

После скрытого `apply_result`: **не** повторяй список замен и **не** рисуй таблицу снова. Максимум: «Готово, правки применены» (если ещё нужен видимый ack). Сырой JSON event не показывай.
