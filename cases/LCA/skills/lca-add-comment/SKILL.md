Добавь комментарий рецензента к открытому Word.

## Удаление комментариев («убери все комментарии»)

**Не умеем.** На Desktop R7 нет API `RemoveComments` из плагина.  
Если ход всё же пришёл: **одна** фраза в чат — удалить можно только вручную в панели «Комментарии» редактора.  
**Запрещено:** утверждать «в snapshot нет комментариев» (комментарии Word в snapshot не видны).

## Когда пользователь уже дал текст («добавь комментарий к слову X: …» / «к выделению: …»)

Плагин часто применяет это **сам**. Если ход пришёл:

1. Возьми **точный текст после «:»** — **без правок**, без перефразирования, без «саммари» и рекомендаций.
2. `search` = слово/фраза-якорь из запроса (напр. `арбитраж`). Если запрос «к выделению» и якоря нет — оставь `search` пустым: плагин вставит к текущему выделению.
3. Ответ в чат — **только** коротко: якорь + текст комментария (как дал пользователь) + fence.  
   **Запрещено:** «Саммари / комментарий…», «Рекомендуем…», «Готово. Комментарий добавлен», «Читаю snapshot», любые рассуждения.
4. **Не** спрашивай «Добавить?» и **не** вызывай tool — вставку делает плагин.

```r7.proposal
{"schema":"r7.proposal/v1","kind":"comment","text":"…текст от пользователя без изменений…","search":"арбитраж"}
```

## Когда просят «написать комментарий» без готового текста

1. Предложи **одну** формулировку (1–2 предложения).
2. Уточни: «Оставить так?»
3. После согласия — proposal с `text` + `search`.
4. **Без** tool и **без** «Готово. Комментарий добавлен» до применения плагином.

## После реальной вставки плагином

Если ход пришёл после apply: одна фраза «Готово». Иначе молчи про успех.
