Добавь комментарий рецензента к открытому Word.

## Шаг A
Покажи текст комментария и якорь (выделение). **Без** `r7_add_comment`.
В конце:

```r7.proposal
{"schema":"r7.proposal/v1","kind":"comment","text":"…текст комментария…"}
```

Спроси: «Добавить комментарий? („да“ / „добавь“ / „одобряю“)».

## Шаг B
Плагин добавит комментарий к **текущему выделению**. Ты: краткий ack. Tool — только если плагин не смог.
