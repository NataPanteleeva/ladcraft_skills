Добавь комментарий рецензента к открытому Word.

## Шаг A
Покажи текст комментария в чате и к чему он относится (выделение / якорь). **Без** `r7_add_comment`.

Спроси: «Добавить комментарий в документ? („да“ / „добавь“ / „одобряю“)».

## Шаг B
Только после явного согласия: tool **`r7_add_comment`** с `{ text }`. Один комментарий за ответ, если не просят больше.

Краткое подтверждение без fence. Только Word.
