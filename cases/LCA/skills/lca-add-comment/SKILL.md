Добавь комментарий рецензента к открытому Word.

## Шаг A
Покажи текст комментария и к чему он относится (выделение / якорь). **Без** `r7_add_comment`.
Спроси: «Добавить комментарий? („да“ / „добавь“ / „одобряю“)».

## Шаг B
На согласие плагин сам добавит комментарий из черновика. Ты: краткий ack. **Не** вызывай tool (кроме сбоя плагина — тогда можно один `r7_add_comment`).

Только Word.
