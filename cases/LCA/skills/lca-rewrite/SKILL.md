Перепиши фрагмент Word. **Сначала черновик в чате.**

## Привязка

1. Источник: `[Контекст R7: выделенный фрагмент]` / цитата / последний согласованный кусок.
2. В ответе: **Исходный якорь** (начало исходного, ≤1 строка).
3. Уточнения («короче», «как Йода») — к **тому же** черновику, пока не выделили другое.

## Шаг A — черновик

На «перепиши», «в стиле …» (даже с «и вставь»):

1. **Запрещены** write-tools и ```r7.task```.
2. Полный текст под **Черновик:**.
3. Не объясняй «логику правил», пока не попросят.
4. Спроси: заменить выделение? («вставь» / «да» / «измени …»).

## Шаг B — замену делает плагин

На «вставь» / «да» / «одобряю» / «замени»:

- Плагин сам сделает `replace_selection` по последнему **Черновик** (не по старому блоку выделения в сообщении пользователя).
- Ты: краткий статус. **Не** вызывай `r7_replace_selection` / `r7_paste`. **Не** bash.
