Итого,: отгружено 12 позиций, и акты подписаны.
Нужно согласовать график, что бы не сорвать поставку.
В течении квартала работы ведутся согласно плана.
Стало быть по мнению заказчика замечаний нет.

## Запрос

`Проверь текст. Только рекомендации.`

## Ожидаемые findings (минимум)

| Паттерн | category |
|---------|----------|
| `Итого,:` → `Итого:` | punctuation |
| `позиций, и акты` → `позиций и акты` (простое «и») | punctuation |
| `что бы не сорвать` → `чтобы не сорвать` | orthography |
| `В течении квартала` → `В течение квартала` | grammar |
| `согласно плана` → `согласно плану` | grammar |
| `Стало быть по мнению` → вводные с запятыми | punctuation |
