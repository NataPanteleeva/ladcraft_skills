# Задания к документу 03 — объявление

**Файл:** [`texts/03-announcement-meeting.docx`](../texts/03-announcement-meeting.docx)  
**Жанр / slug:** объявление (`announcement`)  
**Что заложено:** опечатки (`желаюших`, `колектива`, `оптимизацыи`), размытые «что/когда/где», лишние «!!!», «что бы», «будет производится», нет CTA/даты/места.

Покрывает: **ФТ-01, ФТ-02 (announcement), ФТ-04, ФТ-05**, создание с вставкой (ПМИ 5.3.1).

---

## A. Проверка объявления

1. `Найди грамматические и стилистические замечания. Контекст: объявление. Только рекомендации в чате.`
2. `Проверь: хватает ли в объявлении что / когда / где / для кого / призыв к действию?`

→ `lca-proofread`, slug `announcement`; отдельно — структурные замечания по RULES объявления.

## B. Правки после согласия

3. `исправь все`
4. `исправь 1, 2` (если нужна выборочная проверка)

## C. Генерация «правильного» анонса (ФТ-05 / ПМИ 5.3.1)

5. `Составь короткое объявление о собрании 20 июля в 15:00, аудитория 301, для всех сотрудников. Только в чат.`
6. Курсор в конец файла → `вставь` / кнопка «Курсор».
7. `Составь объявление о том же собрании и вставь в документ в позицию курсора.` (если агент/плагин поддерживает явную просьбу вставки в одном ходе — проверить фактическое поведение: proposal + согласие).

## D. Перепись существующего текста

8. `Перепиши это объявление по правилам анонса: чётко что, когда, где, для кого, CTA. Только в чат.`
9. Выделить старое объявление → `замени выделенное` на согласованный черновик.

## E. Стиль executive (перепись)

10. `Сжать объявление в краткую выжимку для руководства / в тезисах для совещания. Только в чат.`

→ `lca-compose`, slug `executive`.

## F. Повторная проверка

11. После вставки нового текста: `Проверь новое объявление ещё раз.`

## G. Эталон (опечатки + стиль)

| Тип | Пример |
|-----|--------|
| Опечатка | желаюших → желающих; колектива → коллектива; оптимизацыи → оптимизации |
| Орфография | что бы → чтобы |
| Согласование | будет производится → будет производиться |
| Структура | нет даты/места/времени; «примерно…»; «кто может» вместо CTA |
| Пунктуация | «Уважаемые коллеги!!!» |
