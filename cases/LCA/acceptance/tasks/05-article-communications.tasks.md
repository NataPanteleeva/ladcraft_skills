# Задания к документу 05 — статья (нейтральный текст)

**Файл:** `[texts/05-article-communications.docx](../texts/05-article-communications.docx)`  
**Жанр / slug:** нейтральный (`general`); дополнительно стили `yoda`, `executive`  
**Что заложено:** опечатки (`Переставл`, `Унивверситеты`, `Сепгодня`, `клиповвым`, `наавык`, `алгоритвмом`) — удобный регресс proofread + analyze + compose.

Покрывает: **ФТ-01…05**, analyze, yoda, lexical replace, повторную проверку, сохранение смысла (ПМИ 5.3.2–5.3.6).

---

## A. Offline-справка плагина (без агента)

1. В плагине открыть ссылки **Что я умею** / **Как работать** — убедиться, что ответ офлайн и про документы (не таблицы).



## B. Analyze

1. `О чем текст?`
2. `Сделай краткое саммари.`
3. `Перечисли этапы эволюции коммуникаций из текста.`

→ `lca-analyze`; **не** смешивать с таблицей опечаток (proofread).

## C. Proofread — рекомендации (ПМИ 5.3.2)

1. `Посмотри, есть ли опечатки.`
2. `Проверь текст. Только рекомендации, документ не меняй.`

→ таблица findings; документ без изменений до согласия.

## D. Применение / выборочно / Undo (регресс плагина)

1. `исправь 1` → проверить одну замену.
2. Ctrl+Z в редакторе → кнопка **Все** / `исправь все` — правки должны реально примениться снова.
3. `исправь 2, 4` — выборочно.



## E. Лексическая замена

1. `.`
2. `Замени «Сепгодня» на «Сегодня».`



## F. Compose / стили

1. `Можешь переписать короче?` (весь текст / смысл сохранить) — только чат, затем вставка по кнопке.
2. Выделить заключение → `Перепиши выделенный фрагмент как Йода. Только в чат.`
3. `Проверь: достаточно ли текст звучит как Йода? Только замечания.` (на черновике Йоды)
4. `Перепиши выделенное для руководства / в тезисах. Только в чат.`



## G. Комментарий + повтор

1. Выделить предложение с «алгоритвмом» → `Добавь комментарий рецензента: опечатка в корне.`
2. После правок: `Проверь документ ещё раз.`
3. `Смысл статьи после правок сохранился?`
