# Задания к документу 04 — служебный отчёт

**Файл:** [`texts/04-report-june.docx`](../texts/04-report-june.docx)  
**Жанр / slug:** отчёт (`report`) + стиль `executive`  
**Что заложено:** канцелярит и вода («в целом и в принципе»), опечатки (`соответсвии`, `отразится`), размытые сроки («в ближайшее время»), слабая структура рисков/планов.

Покрывает: **ФТ-01, ФТ-02 (report), ФТ-05**, стили **executive**, саммари, ПМИ 5.3.6.

---

## A. Саммари / вопросы (analyze)

1. `О чём отчёт? Кратко по разделам.`
2. `Сделай краткое саммари всего документа.`
3. `Какие риски указаны и насколько они конкретны?`

→ `lca-analyze`.

## B. Проверка как отчёта

4. `Проверь стиль служебного отчёта. Только рекомендации в чате.`
5. `Проверь на опечатки и стилистику. Вид: отчёт.`

→ `lca-proofread`, slug `report`.

## C. Выжимка для руководства (executive)

6. `Проверь: достаточно ли текст краток для руководства? Только замечания в чате.`
7. `Перепиши документ для руководства / сжать в тезисы для совещания. Только в чат.`
8. `Сжать текст в управленческий brief для начальства. Вставь у курсора после согласования.`

→ `lca-proofread` / `lca-compose`, slug `executive`.

## D. Генерация отчёта с нуля (ФТ-05)

9. Новый пустой абзац / новый файл при необходимости:  
   `Сгенерируй краткий отчёт за июнь: выполнено 3 задачи, 1 риск по срокам. Структура как служебный отчёт. Только в чат.`
10. `вставь` у курсора.

## E. Правки текущего текста

11. `исправь все` (после таблицы опечаток).
12. Выделить раздел «Планы» → `Перепиши выделенное конкретнее: с датами и ответственными. Только в чат.` → `замени выделенное`.

## F. Комментарий

13. Выделить фразу «в целом и в принципе…» →  
    `Добавь комментарий: убрать воду, оставить факты.`

## G. Эталон замечаний

| Тип | Пример |
|-----|--------|
| Опечатка | соответсвии → соответствии |
| Глагол | отразится → отразиться (в контексте «может …») |
| Стиль | «в целом и в принципе», «затруднения организационного характера» |
| Конкретика | «в ближайшее время», «будут определены дополнительно» без дат |
| Структура report | слабые «итог / риски / планы» для руководства |
