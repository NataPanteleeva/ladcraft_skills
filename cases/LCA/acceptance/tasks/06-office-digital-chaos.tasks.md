# Задания к документу 06 — большой смешанный текст

**Файл:** [`texts/06-office-digital-chaos.docx`](../texts/06-office-digital-chaos.docx)  
**Жанр / slug:** нейтральный (`general`); при желании сравнить с `letter` / `report`  
**Что заложено:** орфография, грамматика, пунктуация, стиль (канцелярит / вода / «ты–Вы»), лексика (`в течении`, `согласно плана`), логика (даты, числа, противоречия).

Покрывает: **ФТ-01** (полный спектр), **ФТ-02** (сравнение контекстов), **ФТ-04**, ПМИ 5.3.2 / 5.3.5 / 5.3.6.

---

## A. Полная проверка (рекомендации)

1. `Проверь текст. Найди орфографические, грамматические, пунктуационные, стилистические и логические ошибки. Только рекомендации, документ не меняй.`

→ секции **Орфографические / Пунктуационные / Грамматические / Речевые** (+ **Логика**); fence с `"category"`; документ без изменений.

## A2. Scoped по категориям

1. `Проверь только орфографию. Только рекомендации.` → только секция орфо.
2. `Предложи стилистические исправления. Только рекомендации.` → только `speech`, без орфо/грамм.
3. `Найди пунктуационные ошибки.` → только пунктуация.

## B. Применение

1. `исправь 1` → одна замена.
2. `исправь стилистику` → только items с `category: speech` (орфо не трогать).
3. `исправь орфографию` → только orthography.
4. Кнопка **Все** / `исправь все` → все пункты **текущего** proposal.

## C. Два контекста (ФТ-02)

1. Выделить абзац про письма (`Добрый день!!!` …) → `Проверь как объявление. Только замечания.`
2. Тот же фрагмент → `Проверь как деловое письмо. Только замечания.`

→ разные акценты правил `announcement` vs `letter`.

## D. Повтор и смысл

1. После правок: `Проверь документ ещё раз.`
2. `Смысл текста после правок сохранился?`
