## Куда и что

### 1. ФТ-03 (правка выделения + «сохранение форматирования»)

**Проблема:** полная сохранность CharacterFormat при replace API не гарантирует. Канон: `RemoveSelectedContent` + `PasteHtml`/`PasteText`. `Delete` через range — нельзя.

**Предлагаемая формулировка ФТ-03:**

> Должна быть реализована возможность правки выделенного фрагмента в документе: при запросе на исправление с передачей выделенного фрагмента система формирует исправленный текст и заменяет выделение в документе Р7-Офис. Форматирование заменённого фрагмента приводится к результатам вставки через средства редактора (в т.ч. PasteHtml); тождество исходного форматирования фрагмента не гарантируется.

---

### 2. ФТ-04 (диалог / рекомендации)

**Проблема:** если «замечания» понимают как Word-комментарии с жизненным циклом через API — Remove/Change комментариев на Desktop недоступны.

**Предложение:** явно: перечень замечаний и вариантов — **в чате плагина**; комментарии Word не обязательный канал.

---

### 3. ФТ-05 (создание + вставка)

**Статус:** реализуемо (`PasteHtml` / `PasteText`).

**Рекомендация (не блокер):** уточнить вставку в **позицию курсора** (или по правилу плагина), без перезаписи всего файла.

---

### 4. §5.2 — режим «правка в документе»

**Предлагаемая формулировка метрики:**

> …агент заменяет выделенный фрагмент исправленным текстом в открытом документе (удаление выделения и вставка исправления средствами API редактора). Сохранение исходного форматирования фрагмента не требуется / не гарантируется.

Не рассчитывать на `SearchNext` / `ReplaceCurrentWord`.

---

### 5. §5.3 / тест-кейс «Выделенный фрагмент заменён…»

**Предлагаемый ожидаемый результат:**

> Выделенный фрагмент заменён исправленным текстом; допускается изменение локального форматирования в пределах вставки редактора. Документ остаётся валидным и открывается без ошибок.

---

### 6. Компонент «Плагин Р7-Офис» (таблица состава)

**Можно закладывать:** чтение выделения/тела, вставка у курсора, замена выделения, SearchAndReplace, AddComment к выделению.

**Не закладывать:** программное удаление/редактирование комментариев, SearchNext, ReplaceCurrent*, гарантированный CharacterFormat при replace, `GetRangeBySelect().Delete`.

**Предложение к назначению плагина:**

> чат; передача выделенного фрагмента и контекста; вставка у курсора; замена выделения исправленным текстом средствами поддерживаемого API редактора.

---

### 7. С-02 — цель сценария

Развести два исхода: (1) только рекомендации в чате; (2) замена выделения в документе — без третьего режима «комментарии Word через API».
